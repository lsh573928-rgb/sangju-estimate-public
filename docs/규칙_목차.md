# 설계 규칙 목차

> 실제 설계 건을 내역 프로그램으로 확정하면서 담당자가 확인한 **현장 규칙**의 목차입니다. 상세 규칙(수치·산식·사례)은 비공개 저장소에 있습니다.
> 규칙을 바꾸면 실제 확정 건과 가상 예제의 테스트가 모두 통과해야 합니다.

| 장 | 제목 | 요지 |
|---|---|---|
| 0 | 전체 원칙 | 야장 → 도면 → 수량산출서 → 내역서 → 원가계산서. 앞 단계의 내용은 다음 단계에 모두 들어간다. 계산은 코드가, AI는 정리·검토만 |
| 1 | 야장 입력 | 측점·폭 생략·폭 급변·접속부·공구·시설물을 적는 표준 형식 |
| 2 | 아스콘 덧씌우기 | 본선·접속 면적, 아스콘·유제 구입량, 노면청소·텍코팅, 차선도색과 접속부 처리, 부대공 |
| 3 | 숭상(맨홀·집수정·지수전·그레이팅) | 깨고 다시 치는 공법, 개소당 수량, 연속 그레이팅 묶음, 내역 품목 대응 |
| 4 | 콘크리트 확포장 | 타설 품, 거푸집 면수, 앙카·철근 |
| 4-1 | 콘크리트 깨기및복구 | 컷팅·앙카는 기존 콘크리트와 접속하는 단부에만, 줄눈은 최대 간격, 와이어메쉬, 폐기물, 도면 배치 |
| 5 | 재료 할증·수량 자릿수 | 할증은 자재 구입량에만, 단위표준 자릿수와 반올림 해석, 관급 구입량 정수 처리 |
| 6 | 도면 | 배치 순서, 글씨·색·선굵기, NOTE 표기, 라벨 자리, 설계변경 표시, 시설물 배치, 위치도 |
| 7 | 수량산출서 | 총괄표 + 산출근거, 내역과 1:1, 공구 → 공통 → 집계 구조, 산출식 표기, 엑셀 수식, 설계변경 두 줄 |
| 8 | 원가계산·단가산출·끝수 | 원가계산서 구조와 양식 선택, 공사비역산, 단가산출 끝수, 깨기 장비·중기운반 차량 선정, 계약내역 |
| 9 | 예산 초과 대응 | 확인 순서와 처리 기록 |
| 10 | 납품 파일 | 납품 묶음 구성, 위치도 그림 이름, 갑지 문구 |

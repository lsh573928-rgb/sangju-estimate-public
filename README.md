# 소규모 건설공사 설계 자동화 — 쇼룸

**[국토교통]** 읍면동 토목직이 직접 설계하는 소규모 건설공사(총공사비 3천만 원 이하)의
**야장 → 도면 → 수량산출서 → 설계내역** 과정을 자동화하는 도구입니다.
현업 지방공무원(토목직)이 AI 코딩 에이전트를 활용해 직접 개발하고 있으며, 실제 설계 건으로 검증하면서 범위를 넓히고 있습니다.
2026년 10월부터는 담당자가 평소 보던 서류 모양(수량산출서·내역서·도면·야장) 그대로 한 화면에서 확인하고 고치는 쪽으로 맞추고 있습니다.

> 이 저장소는 **쇼룸**입니다. 어떻게 돌아가는지와 결과물의 모습만 보여 드립니다. 소스 코드·자료·테스트는 비공개 저장소에 있습니다.
> 아래 샘플은 모두 **가상 예제**(가상 마을·가상 단가)로 만든 결과물이며, 실제 공사명·지번·금액은 들어 있지 않습니다.

![야장 한 장에서 설계도서까지 — 데이터가 흐르는 길](samples/overview/data_map.png)

**사람은 기준을 확정하고, 계산은 코드가 한다.** 결과물의 숫자마다 어떤 규칙·입력에서 왔는지 거슬러 올라갈 수 있습니다.

## 왜 만들었나

읍면동 토목 담당자는 매년 수십 건의 소규모 공사를 자체 설계합니다. 현장 야장을 보고 도면을 그리고,
면적·자재·숭상 수량을 손으로 계산해 수량산출서를 만든 뒤 내역 프로그램에 옮겨 적는 과정이 모두 수작업이고,
읍면동마다 양식이 제각각입니다. 이 도구는 **야장만 표준 형식으로 적으면 도면·산출서가 나오도록** 해
반복 계산을 없애고, 같은 양식을 쓰게 하는 것을 목표로 합니다.

## 흐름

```mermaid
flowchart LR
  A["현장 야장 · GPS RTK 좌표<br/>측점·폭·시설물·표고"] --> B["표준 입력<br/>case.yaml"]
  B --> C["수량 모델<br/>산출식 = 수량 = 엑셀 수식"]
  C --> D["수량산출서<br/>총괄표 + 산출근거"]
  C --> E["도면<br/>전개도·평면도·종평면도·횡단면도"]
  C --> F["내역 품목<br/>산출서와 1:1"]
  F --> G["단가산출·원가계산<br/>품셈 원문 → 일위대가 → 원가"]
  D --> H["납품 묶음<br/>도면·산출서·내역·갑지"]
  E --> H
  G --> H
```

입력 한 번으로 도면·수량산출서·산출근거·납품 묶음까지 만듭니다. 계산은 결정론적 코드가 하고, AI는 규칙 정리·검토·문장 작성에만 씁니다.

## 2026년 10월에 더한 것

10월 12일 이후 비공개 저장소에 들어간 기능입니다. 샘플 그림은 아래 결과물에 들어간 것(배수로 종평면도 — 가상 GPS RTK 좌표)만 있고, 나머지는 글로만 적습니다.

- **서류 작업대** (구현) — 수량산출서는 엑셀 모양, 내역서는 내역 프로그램 모양, 도면·야장·건 폴더를 탭으로 넘겨 보며 확인합니다. 새 건 만들기부터 결과 파일까지 같은 화면 안에서 합니다.
- **말로 고치기** (구현) — "1공구 NO.9 폭 3.8m로 바꿔"처럼 말하면 고칠 목록을 만들고, 담당자가 보고 「적용」해야 다시 계산합니다. 애매한 말은 되묻고, 정답지·단가·계산 결과를 직접 바꾸는 말은 코드가 막습니다. 종단 계획선(관저고·경사·변곡점)도 말로 고칠 수 있고, "~해 줄래?" 같은 부탁도 고치기로 알아봅니다. 다시 그린 도면 쪽에는 '바뀜'을 표시합니다. 인터넷 없이 내 컴퓨터의 AI 모델로 채점합니다 — 131문항에서 GPT-OSS 20B가 97문항을 맞게 처리(고침·되묻기·막기)했고, 잘못 고친 것 0, 짐작해서 고친 것 0이며, 나머지는 되묻거나 막아 사람에게 넘겼습니다(2026-10-25). 무엇이든 담당자가 「적용」하기 전에는 들어가지 않습니다.
- **GPS RTK 좌표 → 종평면도** (구현) — RTK 장비가 내보낸 좌표 파일(점번호·X·Y·Z)을 넣으면 위에 평면, 아래에 종단(지반고)을 그린 종평면도가 나옵니다. 종단 계획선을 정하면 측점마다 터파기 깊이가 횡단면도·토적계산서로 이어집니다.
- **지난 건 양식 가져오기** (구현) — 지난 설계 건의 도면 표제란 문구, 내역 품목 순서, 산출서 머리 문구를 새 건에 그대로 씁니다.
- **업체 설계도서 교차 검사** (구현) — 업체가 낸 도면·수량산출서·내역서의 수량이 서로 맞는지 근거추적표로 보고, 검토 결과 보고서(한글 hwpx, A4 한 쪽)를 만듭니다.
- **공사시방서·설계설명서** (구현) — 건설공사 표준시방서(KCS) 대응표로 공사시방서와 설계설명서 초안을 만듭니다.
- **설계변경 서류** (시제품) — 당초·변경 야장을 비교해 공사비 증감 대비표·물량 대비표(xlsx)와 변경사유서(hwpx)를 만듭니다. 비목 증감 합이 총공사비 차이와 원 단위로 맞지 않으면 멈춥니다.
- **출장복명서·현장사진 위치도** (시제품) — 건 폴더의 현장사진으로 위치도에 번호 핀과 사진 썸네일을 붙이고, 출장복명서 초안(hwpx)을 만듭니다.
- **예산서 읽기** (시제품) — 세출예산서(xlsx·csv·웹 저장 엑셀 등)를 읽어 담당 시설사업 목록을 만듭니다.
- **유역 참고 계산** (시제품) — 수치지형도 등고선으로 유역면적·평균 경사를 구해 배수 수리계산의 참고값으로 씁니다. 담당자 확인 표시가 있어야 계산에 들어갑니다.

<sub>'시제품'은 가상 예제와 시험으로 확인했고, 실제 건에 쓰기 전에 담당자 양식으로 맞추는 중인 것입니다. 지도·좌표·사진은 이 쇼룸에 싣지 않습니다.</sub>

<sub>왼쪽: 위치도 · 오른쪽: 편입용지도 — 샘플은 **가상 마을 그림과 가상 필지**로 만들었습니다(실제 항공영상·지도·지적·소유정보 아님). 조서: [PDF](samples/location_tool/sheet.pdf) · [그림](samples/location_tool/sheet_table.png)</sub>

- 현장에서 시점·종점·관 위치를 휴대폰으로 찍어 두면, 사진 위치정보로 지도에 점이 놓이고 항공영상 위에서 노선을 다듬습니다. GPS 측량 좌표 파일(위도·경도, 측량 원점 좌표)도 그대로 읽습니다.
- 버튼 한 번으로 위치도(도면 위치도 칸에 맞춘 그림)와 편입예상필지 조서·편입용지도를 만듭니다. 측점만 적은 시설물(횡단관 등)은 설계연장 비례로 노선 위에 놓습니다.
- 조서 비고는 규칙으로 자동: 국·공유지는 관리청 협의, 도면·대장 면적 차이가 크면 측량 확인, 노선이 공공 필지를 벗어나 사유지로 들어가면 지적 이탈(현장 확인).
- 연속지적도 기반 **참고용(법적 효력 없음)** — 면적은 '편입예상면적(참고)', 보상·분할은 지적측량 성과에 따릅니다. 토지 소유자 성명·주소는 조회하지도 저장하지도 않습니다.

<a href="samples/est_review/sheet_summary.png"><img src="samples/est_review/sheet_summary.png" width="49%" alt="검토의견표 요약 — 검사별 건수와 다름 목록"/></a> <a href="samples/est_review/sheet_table.png"><img src="samples/est_review/sheet_table.png" width="49%" alt="검토의견 — 항목별 용역값·기준값·근거·판정"/></a>

<sub>가상 공사의 내역서에 오류 5가지(옛 노임·제비율·총괄표 합계·단가 참조·기계 손료 계수)를 심어 검토한 결과입니다. 검토의견표: [PDF](samples/est_review/sheet.pdf)</sub>

- 용역사가 내역 프로그램으로 납품한 내역서(엑셀 변환 파일)를 넣으면 검토의견표(xlsx)가 나옵니다. 감독 공무원의 검토 보조표이고, 최종 판단은 사람이 합니다.
- 검사 ① 원가계산서: 제비율 요율·적용 여부, 이윤 한도, 부가세, 폐기물처리비 위치, 관급 조달수수료, 끝수 ② 산술: 단가 × 수량, 공종 합계, 총괄표 ↔ 내역서, 일위대가·단가산출 참조 단가 ③ 노임·기계경비: 공표 노임, 품셈 기계경비 기초값으로 다시 계산해 대조.
- 판정은 '같음 · 다름 · 확인 불가'만 씁니다. '다름'은 기준과 값이 다르니 근거를 확인해 달라는 뜻이고, 틀렸다고 단정하지 않습니다(용역사 기준·적용 시점이 다를 수 있음). 끝수 방식 차이(반올림·버림)는 같음으로 두고 의견에 적습니다.
- 실제 용역 성과품은 기관 컴퓨터의 코드로만 검토하고 외부 AI로 보내지 않습니다.
